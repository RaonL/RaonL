# F5 전문가 시스템 구축 플랜

## 1단계) 설계 고정 (반나절)
- F1~F5 책임 범위 확정
- 라우팅 기준(intent/keyword/risk) 확정
- 금지/주의 응답 정책 확정

산출물:
- `configs/experts.yaml`
- `configs/system.yaml`

## 2단계) OpenCLO 에이전트 등록 (1일)
- Orchestrator + F1~F5 에이전트 생성
- 각 프롬프트 연결
- 세션 설정키(톤/포맷/길이) 매핑

산출물:
- 에이전트 ID 목록
- 환경변수/시크릿 설정

## 3단계) 툴/데이터 연결 (1~2일)
- 검색/DB/문서검색 도구 연결
- 도메인별 툴 접근권한 분리
- 감사로그와 호출로그 저장

검증:
- 질문 50개 기준 응답 성공률/지연시간 측정

## 4단계) 운영 안정화 (지속)
- 실패 질문 리플레이 자동화
- 라우팅 오분류 샘플 재학습
- 주간 품질 리포트(정확도, 재질문율, 평균 응답시간)

---

## MVP 수용 기준
- 평균 응답시간 3초 이내
- 라우팅 정확도 85% 이상
- 민감정보 누출 0건
- 설정 요청 반영률 95% 이상
